RULES OF THE ROAD

Predictable and deliberately narrow

  • Dates use YYYY-MM-DD.
  • Counts are whole numbers from 0 through 70,000.
  • Future dates are rejected.
  • Active challenges accept only dates in their inclusive challenge range.
  • POST never overwrites; PUT explicitly replaces an existing entry.
  • Every operation is isolated to the token owner and recorded in the API audit log.
